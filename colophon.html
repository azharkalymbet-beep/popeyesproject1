How This Site Was Built

This colophon details the construction of the website for our project. The site is built using pure semantic HTML markup without any external or internal CSS style sheets, adhering strictly to standard web technology guidelines.

Technologies and Tools Used

To create and verify the markup, we used terminal commands such as git status and git commit to track our progress in GitHub.

Below is a sample code snippet representing our core HTML semantic block structure:


<header>
    <h1>Site Title</h1>
    <nav> Navigation Links </nav>
</header>

When running validation tests locally, terminal outputs appear as follows:

Document checking completed. No errors found.
