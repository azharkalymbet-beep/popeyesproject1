# Popeyes Project 1

Website project for the Introduction to Web Technologies course (Group SE-2534).

## Developers
- Students: Kalymbet Azhar,Batyrgali Akdana
- Group: SE-2534

## Project Description
A multi-page website about Popeyes fast-food restaurant built with pure HTML5. No CSS or JavaScript was used, following strict project requirements.

## Files in Repository
- index.html - Main page
- colophon.html - Technical details and page layout explanation
- contact.html - Store locations and contact info
- reviews.html - Customer reviews and photos
- images/ - Self-taken photographs
- TAG_CHECKLIST.md - HTML tags placement checklist

## Requirements Met
- Pure semantic HTML5 (no external or inline CSS/JS)
- Validated with W3C Markup Validation Service
- Images formatted with <figure>, <figcaption>, and alt attributes
- Tables with standard HTML border and cell attributes
